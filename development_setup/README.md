# Development Setup

Examples for setting up a productive local development environment for Databricks
work — authoring code and notebooks in an IDE, running them against a workspace,
and deploying with Databricks Asset Bundles.

## Sub-projects

| Sub-project | Contents |
|-------------|----------|
| [`vscode_example/`](./vscode_example) | Local IDE workflow with **Databricks Connect**, **VS Code**, and **Databricks Asset Bundles** — environment setup (`uv`, `pyproject.toml`), a reusable `src/` package, and demo notebooks. Start with its [`GUIDE.md`](./vscode_example/GUIDE.md). |
